## Установка на Windows

1. Скачайте `Tempo-Setup-0.5.1.exe` и откройте его.
2. Если появится синее окно «Windows защитила ваш компьютер», нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Это нормально для новых программ без платной подписи.
3. Нажимайте «Далее», пока установка не закончится. Tempo появится на рабочем столе и в меню «Пуск».

## Установка на Mac

1. Скачайте файл `.dmg` и откройте его.
2. Перетащите значок **Tempo** в папку **«Программы»**.
3. Первый запуск: откройте «Программы», нажмите на Tempo **правой кнопкой** → **«Открыть»** → **«Открыть»**.
   Если Mac всё равно не даёт открыть: **Системные настройки → Конфиденциальность и безопасность**, внизу нажмите **«Всё равно открыть»**.
4. Когда Mac спросит, можно ли Tempo управлять **System Events**, нажмите **«Разрешить»**: так Tempo видит, в каком приложении вы работаете.

После первого запуска Tempo откроется с короткого знакомства: выберите язык и оформление, и можно начинать.

### In English

**Windows:** open `Tempo-Setup-0.5.1.exe`. If you see "Windows protected your PC", click **More info → Run anyway**, then follow the installer.

**Mac:** open the `.dmg` and drag Tempo into Applications. The first time, right-click Tempo → **Open** → **Open** (or allow it in System Settings → Privacy & Security). Allow Tempo to control System Events when asked.

These one-time warnings appear because the app isn't signed with a paid developer certificate yet. It's safe to open.
